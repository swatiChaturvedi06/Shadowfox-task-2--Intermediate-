# Delhi Air Quality Analysis

## 📌 Project Overview
This project was completed as part of the ShadowFox Data Analytics Internship (Intermediate Level). The objective of this project is to analyze Delhi's air quality data, perform data preprocessing, and create meaningful visualizations to identify pollution trends and environmental insights.

## 🎯 Objectives
- Analyze Delhi air quality data
- Clean and preprocess the dataset
- Perform exploratory data analysis (EDA)
- Visualize pollution trends
- Generate meaningful insights
